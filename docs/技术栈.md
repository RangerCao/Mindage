# LightRAG 技术栈

## 一、总览

```
                  ┌──────────────────────────────────────┐
                  │          LightRAG 技术栈              │
                  │                                      │
                  │  后端: Python 3.10+  │ 前端: React 19 │
                  │  框架: FastAPI       │ 框架: Vite 6   │
                  │  包管理: uv          │ 包管理: Bun    │
                  │  图谱: NetworkX/Neo4j│ 渲染: Sigma.js │
                  │  向量: NanoDB/Milvus │ 样式: Tailwind │
                  └──────────────────────────────────────┘
```

---

## 二、后端技术栈

### 运行环境

| 技术 | 版本要求 | 说明 |
|------|----------|------|
| **Python** | ≥ 3.10 | 异步优先，类型注解 |
| **uv** | latest | 包管理器（推荐），比 pip 快 10-100x |
| **pip** | - | 备选包管理 |

### Web 框架

| 技术 | 版本 | 用途 |
|------|------|------|

## 五、依赖规模

```
后端核心依赖:     ~25 个包
后端 API 额外:    ~18 个包  
后端离线存储额外:  ~10 个包
前端生产依赖:     ~50 个包
前端开发依赖:     ~15 个包
```

项目支持按需安装，通过 extras 控制：

```bash
uv sync                        # 仅核心
uv sync --extra api            # + API 服务
uv sync --extra offline-storage # + 存储后端
uv sync --extra offline-llm    # + LLM 提供者
uv sync --extra test           # + 测试工具
```
